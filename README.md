- 🏗️ 理解 TiDB 的分布式架构和核心原理

- 🛠️ 具备 TiDB 的故障排查能力

- 📝 通过面试题库巩固知识点

## 🚀 快速开始

### 环境要求

- Docker (推荐)
- 或具备 Linux/Unix 环境
- 至少 8GB 内存
- 至少 50GB 磁盘空间

### 本地部署

```bash
# 克隆项目
git clone <your-repo-url>
cd tidb-learning

# 使用 Docker 快速启动 TiDB
docker run -d --name tidb-server \
  -p 4000:4000 -p 10080:10080 \
  pingcap/tidb:v7.1.1

# 连接 TiDB
mysql -h 127.0.0.1 -P 4000 -u root

# 或使用 TiUP
curl --proto '=https' --tlsv1.2 -sSf https://tiup-mirrors.pingcap.com/install.sh | sh
tiup playground
```

### 验证安装

```sql
-- 连接后执行
SELECT VERSION();
SHOW VARIABLES LIKE '%version%';
```
